09 · Font

  • One Font row under Whole device opens this list; each line is drawn in its font (here approximated with Mac fonts).
  • Uses Android's built-in fonts, so nothing to download or copy; your current Moaan font stays first so you can go back.
  • Applies live (verified): apps redraw in the new font in place.
  • Heavier weights (Medium, Bold) are the e-ink win: thin strokes break up at 16 grays.
  • No Shizuku needed.
